One image that sums up the world's news of **Sunday, 22 November 2026** —
**35 stories** in a single newspaper page: 10 headline stories with short
summaries, and 25 more stories in brief.

The program (`main.ts`, Node 22, standard library only) copies the rendered
image `entry.png` (1024×1024 PNG) to `/output/entry.png`. It reads nothing
else, makes no network request, and two runs write byte-identical output.
